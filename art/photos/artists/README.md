# Sanatçı profil fotoğrafları

23 Kasım 2026 tarihinde kullanıcının verdiği Instagram hesaplarının herkese açık `og:image` profil görsellerinden indirildi:

- `irem-profile.jpg`: https://www.instagram.com/atelier.tue/
- `beyza-profile.jpg`: https://www.instagram.com/beyzaornekl/
- `aysegul-profile.jpg`: https://www.instagram.com/asheluldag/

Bunlar 150 × 150 piksel profil fotoğraflarıdır; eser/ürün fotoğrafı değildir. Sanatçı kartlarında 72 × 72 piksel gösterilir. Dosyalar yerel olarak sunulduğu için ziyaretçinin tarayıcısı fotoğraflar için Instagram’a bağlanmaz.

Her sanatçıdan istenen üç gönderi fotoğrafı alınamadı: herkese açık profil yanıtları gönderi görsellerini sunmadı. Eser fotoğrafları kullanıcıdan geldiğinde ayrıca eklenmelidir; bu profil fotoğrafları ürünlere atanmadı.
